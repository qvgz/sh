```bash
bash utils/is-wall-run.sh 'echo 探测失败' 'date'
```

- 依赖 curl；命令字符串由 bash -lc 执行，必须可信。探测受代理和网络故障影响，不能据此判定是否在墙内。

功能需求：
- 无参数直接返回 0，不进行探测；缺少 curl 返回 3。
- GET 请求 https://www.google.com/generate_204，连接超时 3 秒、总超时 5 秒，不跟随重定向，沿用 curl 代理配置。
- 请求成功且状态码为 204 时返回 0；否则依次执行全部命令字符串，中途失败仍继续。
- 探测失败但命令均成功返回 1；任一命令失败返回 2。
