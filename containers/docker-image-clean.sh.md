```bash
bash containers/docker-image-clean.sh
```

- 需要 Docker 访问权限；会删除旧标签并清理全部悬空镜像，不强制删除。执行前确认镜像可重新拉取或构建。
- 当前固定保留 5 个；虽允许一个参数，但未读取该参数，帮助文本中的“默认 3”与实现不符。

功能需求：
- 按 docker image ls 默认创建时间倒序，每个仓库保留最近 5 个不同镜像 ID；同 ID 多标签只占一个名额。
- 跳过 <none> 仓库或标签，删除超额镜像的各标签；继续执行 docker image prune -f。
- 任一删除或清理失败返回非零；超过一个参数返回 2。
