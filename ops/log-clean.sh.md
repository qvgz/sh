# 日志轮转清理

`bash log-clean.sh 日志目录 ['重开日志命令字符串']`

1. 目录不存在即失败；实例锁避免同目录并发轮转。
2. 将目录顶层普通 `.log` 移到 `backup/昨日日期/`；重名加 `.1.log` 等序号，保留已有备份。
3. 执行可选重开命令；失败立即退出，已移动文件不自动回退，也不清理历史备份。
4. 删除 `backup` 下 `mtime +90` 的 `.log` 和空子目录，保留 backup 根目录。

依赖 Linux GNU `date`/`find`、`flock`，保留期固定 90 天。命令字符串必须可信；服务须能重开日志，否则继续写入备份。恢复时停止写入并将备份移回。
